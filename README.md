# בוט תשובות אוטומטי לפורום NodeBB

שרת Node.js לבוט תשובות אוטומטי, יחד עם פאנל משתמש לשליטה דרך Tampermonkey/Violentmonkey.

## פריסה ב-Render

המאגר כולל `render.yaml` לפריסה כ-Blueprint. השירות מתוכנן לחבילת Free ומחזיר `200 OK` ב-`/health`.

במהלך יצירת ה-Blueprint יש להגדיר את משתני הסביבה הסודיים:

- `BOT_USER` — שם המשתמש הייעודי של הבוט בפורום.
- `BOT_PASS` — סיסמת חשבון הבוט בפורום.
- `GEMINI_KEY` — מפתח API של Gemini.

`ADMIN_TOKEN` נוצר אוטומטית על ידי Render. אין להכניס סיסמאות או מפתחות לקוד או למאגר Git.

## הפעלה ראשונית

1. יש לוודא שמנהלי הפורום מאשרים שימוש בבוט ובתגובות אוטומטיות.
2. להמתין לפריסה ולוודא שהשירות זמין ב-`/health`.
3. להתקין את `forum-bot-panel.user.js` ב-Tampermonkey או Violentmonkey.
4. בפאנל, להגדיר את כתובת השירות ואת `ADMIN_TOKEN` מתוך Environment ב-Render.
5. הבוט כבוי כברירת מחדל. לבדוק את ההגדרות ולהתחיל עם מגבלת תגובות נמוכה לפני שמפעילים אותו.

## מגבלות אחסון

במסלול החינמי, קובץ המצב המקומי `data/state.json` אינו אחסון קבוע בין כל הפריסות וההפעלות מחדש. לאחר הפעלה מחדש ההגדרות עשויות לחזור לברירת המחדל, והבוט כבוי כברירת מחדל.

## מקומית

דרישה: Node.js 18 ומעלה.

```bash
npm ci
npm start
```

השרת דורש `BOT_USER`, `BOT_PASS`, `GEMINI_KEY`, ו-`ADMIN_TOKEN` לפני ההפעלה.
