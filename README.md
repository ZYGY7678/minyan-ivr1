# בוט תשובות אוטומטי לפורום NodeBB

בוט Node.js לפורום NodeBB עם אתר שליטה בעברית, המוגש מאותו שירות.

## קבצים

- `server.js` — שרת, התחברות לפורום, יצירת תשובות, תזמון ו-API מאובטח.
- `dashboard.html` — ממשק השליטה, מפתחות, שעות פעילות, סינון, יומן וטיוטות לאישור.
- `render.yaml` — הגדרות לפריסה ב-Render.
- `forum-bot-panel.user.js` — פאנל חלופי לדפדפן; אינו נדרש כאשר משתמשים באתר השליטה.

## פריסה והגדרה

השירות מוגדר ל-Node.js 18 ומעלה, ללא חבילות חיצוניות. ב-Render נדרש משתנה סביבה אחד: `ADMIN_TOKEN`, המשמש כסיסמת הכניסה לאתר השליטה. קובץ ה-Blueprint מייצר אותו אוטומטית בפריסה חדשה.

1. פתח את כתובת השירות והתחבר באמצעות `ADMIN_TOKEN`.
2. בכרטיס "חיבורים ומפתחות" הזן את כתובת הפורום, פרטי משתמש בוט ומפתח Gemini.
3. השתמש בכפתורים "בדוק התחברות לפורום" ו-"בדוק Gemini".
4. מומלץ להתחיל במצב "טיוטה לאישור", עם מגבלת תגובות נמוכה. הבוט כבוי כברירת מחדל.

אין לשמור סיסמאות או מפתחות ב-GitHub. האתר מציג רק מצב קיום של הסודות, לא את ערכיהם המלאים.

## אחסון

מצב האפליקציה נשמר ב-`data/state.json`. במסלול Render החינמי מערכת הקבצים זמנית, ולכן הגדרות, מפתחות, טיוטות ורשימת נושאים שטופלו עלולים להתאפס לאחר הפעלה מחדש או פריסה. לשמירה מתמשכת יש להגדיר אחסון קבוע מתאים, או לספק ערכי גיבוי באמצעות משתני הסביבה המתאימים.

## הרצה מקומית

נדרש Node.js 18 ומעלה:

```bash
npm install
npm start
```

כתובת בדיקת הבריאות: `/health`. יש לוודא שמותר לפי כללי הפורום להשתמש בבוט ולפרסם תגובות אוטומטיות.
