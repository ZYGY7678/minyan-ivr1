# בוט תשובות אוטומטי לפורום NodeBB

שרת Node.js לבוט תשובות אוטומטי יחד עם פאנל שליטה דרך Tampermonkey/Violentmonkey.

## פריסה ב-Render

השירות מוגדר בקובץ render.yaml ומשתמש ב-Node.js. הוא מחזיר 200 בנתיב /health, והבוט כבוי כברירת מחדל. השרת יכול לעלות במצב הגדרה חלקית כדי לאפשר לבדוק את השירות ולהגדיר את הסודות לאחר הפריסה.

לפני שמפעילים את הבוט, יש להגדיר ב-Render את משתני הסביבה הסודיים:
- BOT_USER — שם המשתמש הייעודי של הבוט בפורום.
- BOT_PASS — סיסמת חשבון הבוט בפורום.
- GEMINI_KEY — מפתח API של Gemini.
- ADMIN_TOKEN — טוקן סודי לפאנל השליטה.

אין להכניס סיסמאות או מפתחות לקוד או למאגר Git. יש לוודא שמנהלי הפורום מאשרים שימוש בבוט ובתגובות אוטומטיות.

## הפעלת הפאנל

1. להתקין את forum-bot-panel.user.js ב-Tampermonkey או Violentmonkey.
2. לפתוח את הפאנל בפורום ולהגדיר את כתובת השירות ב-Render.
3. להעתיק את ADMIN_TOKEN מתוך Environment ב-Render אל הפאנל.
4. לוודא שמופיע שפרטי הבוט מוגדרים, ואז לבדוק שהחיבור לפורום תקין.
5. להפעיל בהדרגה, עם מגבלת תגובות נמוכה בתחילה.

## הפעלה מקומית

דרישה: Node.js 18 ומעלה.

    npm ci
    npm start

## אחסון

במסלול החינמי, קובץ המצב המקומי data/state.json אינו אחסון קבוע בין כל הפריסות וההפעלות מחדש. הגדרות ורשימת הנושאים שנענו עשויות להתאפס; ברירת המחדל היא שהבוט כבוי.
